# 练习1: 分数等级判断

## 问题描述

编写一个程序，根据用户输入的分数，输出对应的等级（优秀、良好、及格、不及格）。

## 输入输出示例

输入：
```
85
```

输出：
```
良好
```

## 提示

- 使用input()函数获取用户输入
- 使用int()函数将输入转换为整数
- 使用if-elif-else语句判断等级
- 等级划分：90分及以上为优秀，80-89分为良好，60-79分为及格，60分以下为不及格

## 参考解答

```python
# 获取用户输入的分数
score = int(input("请输入分数: "))

# 判断等级
if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

# 练习2: 打印偶数

## 问题描述

编写一个程序，使用for循环打印1到100之间的所有偶数。

## 输入输出示例

输入：无

输出：
```
2
4
6
...
98
100
```

## 提示

- 使用range()函数生成1到100的数字
- 使用for循环遍历这些数字
- 使用条件判断筛选出偶数
- 使用print()函数打印结果

## 参考解答

```python
# 使用for循环打印1到100之间的所有偶数
for i in range(1, 101):

        print(i)

# 或者使用步长为2的range()函数
# for i in range(2, 101, 2):
#     print(i)
```

# 练习3: 计算1到100的和

## 问题描述

编写一个程序，使用while循环计算1到100的和。

## 输入输出示例

输入：无

输出：
```
1到100的和为: 5050
```

## 提示

- 初始化一个变量sum为0
- 初始化一个变量i为1
- 使用while循环，当i小于等于100时执行循环体
- 在循环体中，将i加到sum中，然后i加1
- 循环结束后，打印sum的值

## 参考解答

```python
# 初始化变量
sum = 0
i = 1

# 使用while循环计算1到100的和
while i <= 100:
    sum += i
    i += 1

# 打印结果
print(f"1到100的和为: {sum}")
```

# 练习4: 打印九九乘法表

## 问题描述

编写一个程序，打印九九乘法表。

## 输入输出示例

输入：无

输出：
```
1×1=1	
1×2=2	2×2=4	
1×3=3	2×3=6	3×3=9	
...
1×9=9	2×9=18	3×9=27	4×9=36	5×9=45	6×9=54	7×9=63	8×9=72	9×9=81	
```

## 提示

- 使用嵌套for循环
- 外层循环控制行数（1到9）
- 内层循环控制每行的列数（1到当前行数）
- 使用print()函数打印每个乘法表达式，使用end="\t"保持在同一行
- 每行结束后使用print()函数换行

## 参考解答

```python
# 打印九九乘法表
for i in range(1, 10):
    for j in range(1, i+1):
        print(f"{j}×{i}={i*j}", end="\t")
    print()
```

# 练习5: 列表推导式创建奇数列表

## 问题描述

使用列表推导式创建一个包含1到100之间所有奇数的列表，然后打印该列表。

## 输入输出示例

输入：无

输出：
```
[1, 3, 5, 7, 9, 11, ..., 99]
```

## 提示

- 使用range()函数生成1到100的数字
- 使用列表推导式筛选出奇数
- 使用print()函数打印结果

## 参考解答

```python
# 使用列表推导式创建奇数列表
odd_numbers = [i for i in range(1, 101) if i % 2 != 0]

# 打印结果
print(odd_numbers)
```

# 练习6: 猜数字游戏

## 问题描述

编写一个猜数字游戏，程序随机生成一个1到100之间的数字，用户通过输入数字来猜测，程序提示用户猜大了还是猜小了，直到猜对为止。

## 输入输出示例

输入：
```
50
30
40
45
```

输出：
```
猜大了
猜小了
猜小了
恭喜你，猜对了！
```

## 提示

- 使用random模块生成随机数
- 使用while循环进行猜测
- 使用input()函数获取用户输入
- 使用条件判断提示用户猜大了还是猜小了
- 当猜对时，使用break语句跳出循环

## 参考解答

```python
# 导入random模块
import random

# 生成1到100之间的随机数
target = random.randint(1, 100)

# 猜数字游戏
while True:
    # 获取用户输入
    guess = int(input("请输入一个1到100之间的数字: "))
    
    # 判断猜测结果
    if guess > target:
        print("猜大了")
    elif guess < target:
        print("猜小了")
    else:
        print("恭喜你，猜对了！")
        break
```
