# 练习1: 打印个人信息

## 问题描述

编写一个Python程序，打印你的名字、年龄和所在城市。

## 输入输出示例

输入：无

输出：
```
姓名: 张三
年龄: 20
城市: 北京
```

## 提示

- 使用`print()`函数打印信息
- 使用字符串拼接或f-string格式化字符串
- 可以使用变量存储个人信息

## 参考解答

```python
# 打印个人信息
# 使用变量存储个人信息
name = "张三"
age = 20
city = "北京"

# 使用f-string格式化字符串并打印
print(f"姓名: {name}")
print(f"年龄: {age}")
print(f"城市: {city}")
```

# 练习3: 输出当前日期和时间

## 问题描述

编写一个Python程序，输出当前的日期和时间。

## 输入输出示例

输入：无

输出：
```
当前日期和时间: 2023-10-01 12:34:56
```

## 提示

- 使用`datetime`模块获取当前日期和时间
- 使用`strftime()`方法格式化日期和时间

## 参考解答

```python
# 输出当前日期和时间
# 导入datetime模块
from datetime import datetime

# 获取当前日期和时间
current_datetime = datetime.now()

# 格式化并打印
print("当前日期和时间:", current_datetime.strftime("%Y-%m-%d %H:%M:%S"))
```
